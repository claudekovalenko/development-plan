# Digital Collective — MVP build plan

`index.html` is a single, self-contained page for the client. It shows how the MVP is built and paid: three stopping points ($3,000, $3,000 and $4,000, $10,000 in total), what each one delivers, when each is accepted, and what is quoted separately (Phase 1.5, Phase 2, the VisitorReach API handoff and ongoing support).

The content comes from the Digital Collective project proposal and developer scope (sections 2, 14 and 15) and its MVP payment milestones. Open `index.html` in a browser to view it; it needs no build step.

## Putting it live (GitHub Pages)

The page is published by `.github/workflows/pages.yml` whenever this branch (or `main`) is pushed, and can also be run by hand from the **Actions** tab. In **Settings → Pages**, **Source** must be set to **GitHub Actions**.

Live address: `https://claudekovalenko.github.io/development-plan/`

The repository is public, so anyone with the link can read this page.

# Jesus People Network — MVP build plan

`index.html` is a single, self-contained page for the client. It shows how the MVP is built: three stopping points, what each one delivers, when each is accepted, and what is quoted separately (Phase 1.5, Phase 2, the VisitorReach API handoff and ongoing support).

The content comes from the Jesus People Network project proposal and developer scope (sections 2, 14 and 15). Open `index.html` in a browser to view it; it needs no build step.

## Putting it live (GitHub Pages)

The page is published by `.github/workflows/pages.yml` whenever this branch (or `main`) is pushed, and can also be run by hand from the **Actions** tab. In **Settings → Pages**, **Source** must be set to **GitHub Actions**.

Live address: `https://claudekovalenko.github.io/development-plan/`

The repository is public, so anyone with the link can read this page.

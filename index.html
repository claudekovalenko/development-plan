MVP acceptance statement

A new creator can register, receive a unique URL, configure the three journey sections, publish the page, receive trackable audience responses, see their own data/analytics, and the network can see those same responses aggregated across every creator and trigger network-managed follow-up.

Not part of these three payments

Anything outside the MVP list (Phase 1.5, Phase 2, a VisitorReach API handoff and ongoing support) is quoted separately and is not part of these three payments.

Phase 1.5 · near-term enhancements

  • Multi-email nurture sequences and automation builder
  • Additional response types/custom fields
  • Webhook/API integrations with external CRMs/email systems
  • Advanced segmentation, tags, deduplication and saved reports
  • Enhanced application/approval/review tools
  • Localization/multiple languages
  • SMS follow-up after compliant opt-in

Phase 2 · 1–2 year vision

  • First-party church recommendation/search platform
  • Verified church database + church partner portal
  • Closed-loop local church handoff reporting
  • Creator directory/discovery
  • Advanced cohort/funnel benchmarks
  • Public impact dashboard
  • Additional community/app experiences only if validated by usage

Also quoted separately

  • VisitorReach API handoff, if VisitorReach provides a secure API, webhook or partner intake
  • Ongoing support: maintenance, monitoring, backups and bug support

What the MVP covers

The platform has three visible experiences plus one shared data and automation layer. All four are in the MVP.

A · Prospective creators

Network / join site

Explains the vision, beliefs and commitments; invites creator registration.

B · Registered creators

Creator dashboard

Customize the public journey, see data and analytics, export their own records.

C · Public audience

Creator journey page

Presents the three next steps, resources, forms and calls to action.

D · Network staff

CRM + admin

Stores and reports data, manages creators, runs follow-up and integrations.
